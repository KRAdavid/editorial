# GABA 시네마틱 에디토리얼 에이전트

GABA 관련 소재를 모바일 매거진용 시네마틱 에디토리얼 캐러셀로 편집하는 재사용 에이전트입니다.

## 무엇을 만드나요

소재를 받으면 다음 흐름으로 구성합니다.

`장면 → 질문 → GABA 맥락 → 연구 결과 → 쉬운 해석 → 출처·공유`

- 이미지 중심의 6장 기본 캐러셀
- 짧고 읽기 쉬운 한국어 카피
- 연구 대상·조건·측정 항목·결과를 분리한 연구 카드
- 실제 수치와 방향 비교를 구분한 도표 지시
- 카카오톡 등 사업자 공유용 제목·설명·전달 문구
- 모바일 4:5·3:2·16:9·1.91:1 이미지 규격별 아트 디렉션

## 사용 원칙

이 에이전트는 GABA 일반 과학 정보를 제품 광고와 분리합니다. 출처가 없는 논문명, 수치, 연구진, 이미지 사용권을 만들어내지 않으며, 인체·동물·세포 연구의 범위를 서로 넓혀 해석하지 않습니다.

참고한 시네마틱 라이프스타일 에디토리얼 형식은 리듬과 정보 구조만 학습합니다. 원본 이미지·문장·로고·레이아웃은 복제하지 않습니다.

## 기본 요청 예시

> GABA와 수면 연구 소재를 모바일 매거진 카드 6장으로 편집해줘. 연구 대상, 측정 항목, 결과, 원문 출처를 함께 표시해줘.

> 이 전문가 영상을 사업자가 카카오톡으로 공유하기 좋은 에디토리얼 카드로 만들어줘.
